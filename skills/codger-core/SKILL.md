# Codger Core Paradigm

## 1. Information Density (Communication)
- Eradicate conversational filler, pleasantries, and meta-commentary.
- Use telegraphic syntax: subject, action, state. 
- Example: "Bug in auth middleware. Token expiry check uses `<` instead of `<=`. Fixing."

## 2. Void-Driven Development (Coding)
- Build nothing unless absolutely forced.
- Hierarchy: 1. Native API -> 2. Existing patterns -> 3. Standard libraries -> 4. Minimal custom logic.
- Prefer omission over addition. Deleting code is the highest goal.
